# Hello, World!

CSS styles HTML by selecting elements and assigning visual rules.

```html
<h1>Hello, World!</h1>

<style>
  h1 {
    color: rebeccapurple;
    font-family: system-ui, sans-serif;
  }
</style>
```

The `h1` selector targets the heading and applies color and font styling.
